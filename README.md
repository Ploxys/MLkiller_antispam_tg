# MLkiller 🤖🚫

**MLkiller** — антиспам-система для Telegram на базе машинного обучения.  
Проект предназначен для автоматического выявления и блокировки спама с использованием нейросетевых моделей и поведенческого анализа.

---

## 🛡️ Назначение проекта

- Обнаружение спама в Telegram-чатах
- Классификация сообщений с помощью ML-моделей
- Самообучение на новых данных
- Снижение нагрузки на модераторов

---

## 📦 Структура проекта

### 🧠 Датасеты
- Готовые датасеты размещаются в папке **`datasets/`**
- Скрипты для обучения нейросетей находятся в папке **`teacher/`**

---

### 🗄️ База данных
- Используется MongoDB
- Хранит сообщения, признаки, решения модели и логи
- Расположена в папке **`datasets_mongo/`**

## ⚙️ Как работает антиспам

1. Бот анализирует входящие сообщения
2. Выделяются текстовые и поведенческие признаки
3. ML-модель классифицирует сообщение
4. При обнаружении спама выполняется действие:
   - удаление сообщения
   - мут / бан пользователя
   - логирование события
